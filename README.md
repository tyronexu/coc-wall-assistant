# CoC 刷墙助手

一个**纯本地、零依赖、合规**的部落冲突（Clash of Clans）刷墙辅助 PWA 工具。

> ⚠️ **合规声明**：本工具不连接游戏服务器、不模拟点击、不读取游戏内存或拦截网络包，所有数据由用户手动录入，仅做本地数学计算与计时提醒。使用自动化外挂违反 Supercell 服务条款，会导致封号。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 资源规划 | 根据墙等级、目标等级、数量、每日金币产出，计算总成本、完成天数与预计完成日期 |
| 策略速查 | 兵种搭配、匹配值策略、时间窗口、资源管理、合规边界知识库 |
| 训练提醒 | 选择兵种预设与数量，到点本地通知（不读游戏数据，纯计时器） |
| 进度追踪 | 每日记录金币/圣水/墙数，生成累计发育曲线图表 |

## 技术栈

- **纯静态**：HTML + 原生 CSS + 原生 ES Module，无需 npm / 构建步骤
- **IndexedDB**：本地存储每日进度与提醒任务
- **Service Worker**：离线缓存 + 通知触发
- **SVG 折线图**：自实现，无第三方图表库
- **Notification API**：浏览器本地通知

## 本地运行

PWA 必须通过 `http://` 或 `https://` 访问，**不能直接双击 `index.html`**（`file://` 协议下 Service Worker、IndexedDB、Notification 都会受限）。

```bash
# 方式一：Python
python -m http.server 8080
# 浏览器打开 http://localhost:8080

# 方式二：VS Code Live Server 插件
# 右键 index.html → Open with Live Server
```

## 部署到手机

把整个目录拖到任意免费静态托管（Vercel / Netlify / Cloudflare Pages / GitHub Pages），获取 https 链接后：

1. 手机浏览器打开链接
2. 浏览器菜单 → **添加到主屏幕**
3. 桌面会出现 APP 图标，支持离线使用

### GitHub Pages 部署

1. 仓库 Settings → Pages → Source 选 `main` 分支、根目录
2. 等待部署完成，访问 `https://<你的用户名>.github.io/coc-wall-assistant`

## 使用说明

### 资源规划

1. 选择大本营等级（参考墙等级上限）
2. 选择当前墙等级和目标墙等级
3. 输入需要升级的墙数量和每日可刷金币
4. 点击「计算」查看总成本、完成天数、完成日期和逐级成本明细

### 策略速查

直接查阅整理好的打资源策略，包括兵种搭配、Farm 时段、资源管理等。

### 训练提醒

1. 首次使用请授权浏览器通知权限
2. 选择兵种预设（或自定义总秒数）和数量
3. 到点会收到本地通知

> 注意：PWA 后台定时不可靠，提醒功能需要 APP 在前台运行。

### 进度追踪

1. 选择日期，填入当日获取的金币、圣水和完成的墙数
2. 保存后自动生成累计金币 / 圣水 / 墙数的发育曲线
3. 数据全部存储在本地浏览器，不上传任何服务器

## 合规边界

**可以做：**
- 手动操作游戏，自己安排在线时段
- 使用本工具做规划、提醒、追踪
- 使用游戏内官方加速道具

**不要做（会封号）：**
- 宏 / 自动点击器 / 模拟器脚本自动 Farm
- 共享账号给代练或机器人
- 修改游戏内存或拦截网络包

违规封号通常不可申诉，辛苦刷的资源会全部清零。

## 数据说明

城墙升级成本、兵种训练时间等数据参考 Supercell 公开游戏数据，以游戏内实际为准。如需调整，编辑 [`app/data.js`](./app/data.js)。
